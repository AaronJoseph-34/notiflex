# Dependencies and notices

This repository contains Notiflex application source and generated Unity scene/configuration assets. Package source is restored by Unity rather than vendored into this repository.

- Unity Editor/player and engine modules: Unity's applicable license and terms.
- Meta XR Core SDK 209.0.0 and its runtime plugins: Meta/Oculus SDK license supplied with the package, https://developer.oculus.com/licenses/oculussdk/ .
- Unity OpenXR 1.19.0, XR Management, Input System, UGUI and other Unity packages: their package `LICENSE`/third-party notices.
- Unity MCP v10.3.0: https://github.com/CoplayDev/unity-mcp ; license and notices in that dependency. This is editor tooling and is not the notification context classifier.
- Built-in LegacyRuntime font: distributed by Unity as part of its engine resources.

The test rooms use application-authored primitive geometry and materials. The conversation partner is a geometric proxy. No external photographs, photogrammetry models, generative assets or raw camera recordings are included in these Unity VR scenes. The earlier photo-based desktop preview is a separate deliverable with its own photo credits.

Bundled third-party notices generated by Unity remain inside the built packages. No new license is imposed here on the user's original Notiflex paper or project.
