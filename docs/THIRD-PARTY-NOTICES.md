# Dependencies and notices

This repository contains Notiflex application source and generated Unity scene/configuration assets. Package source is restored by Unity rather than vendored into this repository.

- Unity Editor/player and engine modules: Unity's applicable license and terms.
- Meta XR Core SDK 209.0.0 and its runtime plugins: Meta/Oculus SDK license supplied with the package, https://developer.oculus.com/licenses/oculussdk/ .
- Unity OpenXR 1.19.0, XR Management, Input System, UGUI and other Unity packages: their package `LICENSE`/third-party notices.
- Unity MCP v10.3.0: https://github.com/CoplayDev/unity-mcp ; license and notices in that dependency. This is editor tooling and is not the notification context classifier.
- Built-in LegacyRuntime font: distributed by Unity as part of its engine resources.

The test rooms use application-authored primitive geometry and materials. The conversation partner is a geometric proxy. No external photographs, photogrammetry models, generative assets or raw camera recordings are included in these Unity VR scenes. The earlier photo-based desktop preview is a separate deliverable with its own photo credits.

Bundled third-party notices generated by Unity remain inside the built packages. No new license is imposed here on the user's original Notiflex paper or project.

## Local speech models introduced in 0.6.0

Silero VAD is distributed under MIT; source pinned at `066409f3d9db45a30d21dfcbf9147826ffdd7052` in [the official repository](https://github.com/snakers4/silero-vad). The 16 kHz graph is specialized with constant sample rate and static dimensions for Unity compatibility. Original/specialized synthetic outputs are compared; source hashes and conversion details are in `evidence/paper-coverage-0.6.0/speech-model-conversion.json`. MIT text is bundled in `Resources/Notiflex/Silero-LICENSE.txt`.

WeSpeaker ResNet34 English/VoxCeleb embedding weights come from [Sherpa-ONNX's official speaker-recognition release](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-recongition-models); WeSpeaker toolkit code is Apache 2.0. Preserve the model/source provenance and notices in `Resources/Notiflex/SpeechModels-NOTICE.txt` and `WeSpeaker-LICENSE.txt`. Source weights are SHA-256 pinned; static-shape conversion and Unity execution are tested against the original. These pretrained weights are not a Notiflex-trained model or evidence of proprietary novelty.

Model preparation uses ONNX Runtime and ONNX, and feature reference fixtures use kaldi-native-fbank; these Python development tools are not bundled into the Android player. The fixtures contain synthetic signals only. Corresponding source/tool licenses remain applicable. No user microphone recording is included.
